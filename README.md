## Uruchomienie projektu

## Wymagania
zainstalowane:

- Node.js
- npm
- XAMPP

## Instrukcja uruchomienia

## 1. Uruchom XAMPP
Włącz:

Apache
MySQL

## 2. Otwórz terminal/CMD
Przejdź do folderu z projektem:

npm install
npm start

## 3. Otwórz drugi terminal (CMD)
Przejdź do folderu z projektem:

npm run api
