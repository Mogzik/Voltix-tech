## Uruchomienie projektu

## Wymagania
zainstalowane:

- Node.js
- npm
- XAMPP

### Instrukcja uruchomienia

## 1. Uruchom XAMPP
Włącz:

Apache
MySQL
 Dodaj baze danych

## 2. Otwórz terminal/CMD
Przejdź do folderu z projektem:

npm install
npm start

## 3. Otwórz drugi terminal (CMD)
Przejdź do folderu z projektem:

npm run api

## 4. Otwórz trzeci terminal (CMD)
Przejdź do folderu z projektem:

node server.js
